## Overview

AI Scam Message Checker provides a fast way to examine message text directly in a web browser. Its purpose is to highlight scam-related signals in suspicious content without requiring a desktop application or local installation.

The tool uses a straightforward web interface delivered through HTML. As a result, it can be opened, evaluated, and shared in situations where a small, accessible message-checking utility is useful.
